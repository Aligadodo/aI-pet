# 我家女友·甜蜜桌宠 v1.2.4

根据照片形象制作的独立 Windows 逐帧动画桌宠。角色保留圆框银色眼镜、深色中分刘海、盘发与细长编发、珍珠耳饰、金色发饰和白色绒球，以及白色汉服、红橙色袖缘与彩色刺绣云肩等辨识特征。

## 主要功能

- 25 组动作、181 张透明真实帧；走路为 12 帧/14 fps，跑步由 6 帧扩为 12 帧/16 fps，并加入落脚、承重、双脚经过、蹬地和腾空阶段。播放不再依靠重复渲染帧伪增帧，每次更新只显示一个完整角色轮廓。
- 跳跃扩充为 10 帧起跳—腾空—下降—缓冲序列；攀爬和拖拽分别整理为 8 帧稳定循环。睡眠改为一次性入睡后停留，阅读改为始终保持书本打开的往返循环。
- 新增三阶段“拍照 Pose”：举起相机、眨眼拍摄、放下相机比耶；保留伸懒腰、坐下阅读、雨天撑伞、喝热饮等情境动作。
- 376 条恋人日常台词，除了时间、天气和模式，还会在本地识别写代码、写作、表格、会议、浏览、听歌、设计、游戏和阅读等前台活动，触发对应支线。
- 40 类随机情境任务，新增专注小段、保存进度、会议收尾、标签页整理、音乐分享、游戏休息、阅读护眼、喝水、坐姿、桌面整理、心情照顾、拍照纪念等任务。
- 任务会结合时段、工作日/周末、天气和本地活动类别加权触发。选项只支持鼠标点击，面板不抢键盘焦点。
- 日常陪伴、甜蜜互动、安静陪伴、打盹休息四种模式；甜蜜模式会更活泼、跳得更高、任务更频繁。
- 实时视线跟随鼠标，并用方向迟滞与稳定窗口轮廓减少抖动、闪帧。
- 自动在屏幕底部游荡，也会挑选当前真正可见、没有被其他窗口完全遮住的普通窗口进行攀爬和边缘行走。
- 仅统计全局按键频率，不记录具体按键或文字；检测到持续打字或会议时会退到最近屏幕边缘，暂停随机任务、漫游和中间区域互动。
- 手动拖到任意位置后保持原位休息 2/5/10/20 分钟（默认 5 分钟），不会立刻恢复自动游荡；可在菜单中提前恢复。
- 支持“始终置顶”和“只在桌面显示”两种层级，并持久保存选择。
- 可单独开启“猜你喜欢”：后台读取 Google 新闻公开 RSS 与 Apple Music 中国区热门榜，生成临时选择任务；选择后使用系统默认浏览器或音乐页打开。不会上传窗口、标题或输入活动。
- 消息气泡和任务卡片始终跟随角色并避让屏幕边缘；右键菜单打开期间会临时隐藏卡片，避免互相遮挡。
- 整点报时、久坐休息提醒、离开后欢迎回来。

## 使用方法

双击 `SweetGirlfriendDesktopPet.exe` 启动。右键角色或系统托盘图标，菜单分为：

- “现在陪我”：立即任务、猜你喜欢、拍照/阅读/比心等手动动作、可见窗口探险；
- “陪伴模式”：日常、甜蜜、安静、打盹；
- “智能互动”：任务开关和频率、主动台词、情境互动、猜你喜欢；
- “情境与天气”：天气自动识别或手动情境；
- “显示与活动”：置顶/仅桌面、窗口漫游、手动摆放休息时长、暂停；
- “隐私与联网”：查看本地统计说明并手动刷新公开缓存。

“红包”仅为本地趣味选项，不会打开付款页面，也不会执行真实转账。

自动天气会通过 `wttr.in` 按公网地址获取近似本地天气，不请求 GPS；也可在菜单中改为纯本地手动天气模式。联网失败不影响桌宠运行。

猜你喜欢默认开启，可在“智能互动”中单独关闭。它只请求公开榜单，不附带前台窗口、活动类别、按键频率或其他本地信息。

```powershell
python app.py --qa-window --qa-animation=walk
python app.py --qa-window --qa-task
python app.py --qa-window --qa-photo
```

程序设置使用 `SweetGirlfriendDesktopPet/GirlfriendPet` 独立命名空间，不会覆盖此前的美短或狸花桌宠。
