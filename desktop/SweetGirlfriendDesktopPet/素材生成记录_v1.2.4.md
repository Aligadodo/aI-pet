# v1.2.4 动作素材生成与修订记录

## 图像生成方式

- 使用 Codex 内置图像生成工具，以 v1.2.3 待机帧和跑步帧为角色身份、服装、配色和渲染参考。
- 生成 4×3 跑步动作母版，背景使用纯色绿色键控；本地去除背景后，逐格裁切并统一到 512×512 透明画布。
- 另生成跑步“经过阶段”关键姿势，用于补足双脚收回身体下方的中间过程。

## 关键约束

- 保持圆框眼镜、盘发、白色绒球、发饰、编发、白红汉服和刺绣图案。
- 全身、双脚和鞋底必须完整；禁止长腿、踮脚悬空视角、裁脚、额外肢体和投影。
- 每帧只保留一个完整不透明角色轮廓，不使用整人物透明叠化。
- 走路与跑步统一角色高度、中心和脚底基线，只保留动作需要的小幅垂直起伏。

## 本地后处理

- 使用 imagegen 技能自带 `remove_chroma_key.py` 进行软边缘去背景和去绿色溢色。
- 通过 `revise_animations_v124.py` 裁切生成母版、清理跨格碎片、统一尺寸与脚底锚点，并重排其他动作。
- 通过 `audit_animation_quality.py` 输出全部动作接触表和 JSON 指标报告。
