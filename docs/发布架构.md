# 桌宠程序与资源包双发布架构

## 产线 A：桌宠运行程序

源码：`android/SweetGirlfriendPetAndroid`

发布内容：APK、安装说明、运行时协议兼容表。运行程序负责 Android 权限、窗口层级、背景呈现、互动频次、节能、渲染、安全安装和扩展点实现。

## 产线 B：桌宠资源包

源码：`petpack/PetPack-v2`

发布内容：`.petpack`、SHA-256、资源包版本说明。资源包负责角色媒体、动作、台词、行为权重、任务和声明式扩展数据。

## 版本关系

- APK 与资源包分别升级，不要求版本号一致；
- 资源包通过 `protocol.minRuntime` 声明最低运行程序；
- 运行程序支持 PetPack 2.x，并按扩展 ID/API 版本协商；
- 未知可选扩展忽略，未知必需扩展拒绝；
- 同 ID 新资源包可以通过局域网页覆盖安装，失败自动保留旧版本。

## 局域网发布流程

1. 在电脑的资源包项目中运行 `python tools/petpack.py publish <pack> --android-project ../../android/SweetGirlfriendPetAndroid`；该入口会执行协议、语义、动画、确定性构建和 Android 模拟器安装门禁；
2. 在 Android 应用内开启“局域网上传”；
3. 电脑访问应用显示的 IP、随机端口和令牌地址；
4. 网页上传 `.petpack`；
5. 应用验证协议、扩展、路径、大小和 SHA-256 后安装并刷新角色列表。

`validate`、`qa` 和 `build` 可用于开发期检查，但不单独构成正式发布。正式 `.petpack` 必须通过 `publish`，并保留匹配的 SHA-256、QA 报告和 Android install-gate 报告。
