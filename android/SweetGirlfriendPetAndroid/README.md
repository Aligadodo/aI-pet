# 我家女友·甜蜜桌宠 Android v0.5.5

v0.5.5 继续保持“运行程序 APK”和“桌宠资源包 `.petpack`”两条独立发布线。APK 提供权限、渲染、悬浮/壁纸、节能、动态上下文、声明式游戏引擎，以及经用户授权的本地资源包扫描与确认安装；角色图片、动作、头像、台词、任务和玩法兼容信息由资源包提供。本版 APK 自动内置经典汉服、JK 海边夏日和南大校园三套资源包，仍可继续安装后续兼容包。

## 本版新增

- 局域网上传改为“电脑裸地址 + 6 位配对码”：直接输入 `http://IP:端口/` 即可看到配对页，不再要求手工输入长令牌；仍保留完整链接兼容入口，配对 Cookie 为 `HttpOnly / SameSite=Strict`，错误尝试会限速；
- LAN 连接增加单客户端异常隔离、2 worker + 4 queue 有界并发、空闲超时、请求头行数/32 KiB 总预算和重复头拒绝；Home、息屏和异常空闲连接不再导致服务崩溃或无界占用；
- vivo/国产文件管理器兼容：单/多文件选择为推荐入口，增加 `ACTION_GET_CONTENT` 兼容选择器，并支持从文件管理器通过“打开方式”、单文件分享和多文件分享导入；所有入口仍统一执行私有快照、预检、去重和二次确认；
- vivo 文件元数据兼容：文件名与目录枚举只查询 Android 通用必需列，文件大小和修改时间改为互不影响的可选查询；厂商文件提供方拒绝 `last_modified` 时仍会继续读取实际内容、计算 SHA-256 并进入二次确认；
- PetPack 发布门禁：资源包先完成协议/语义/逐帧 QA 和确定性双构建，再把精确 SHA-256 的候选包送入独立 Android 测试 APK，复用生产安装器验证首次安装、重复安装、冷加载、全部动作与任务；任何失败都不会覆盖上一份发布包；
- 目录扫描会提前解释 Android 11+ 禁止授权内部存储根目录、Download 根目录、`Android/data` 和 `Android/obb`，并优先定位 `Download/PetPacks` 子目录；没有新增全盘存储权限；
- 本地 `.petpack` 导入：通过 Android 系统文件选择器多选文件，或持久授权一个 `Downloads/PetPacks` 等子目录；返回设置页时可节流扫描，但发现候选后绝不自动安装，每份内容都要再次确认；
- 本地导入统一先复制到应用私有缓存并计算 SHA-256，再执行协议、完整性、版本与位图预算预检；相同内容自动跳过，同版本异内容强提醒，降级统一拒绝，并可明确忽略某个内容哈希，避免反复提示；
- 时间/星期/天气上下文台词；天气城市由用户填写，不申请定位权限；查询采用中国大陆可访问的免注册 UAPI 访客额度单请求优先、Open-Meteo 免密备用，成功结果缓存并每 2 小时自动刷新；国内源遇到限流或故障会长退避，同城市在途请求共享结果，旧城市请求和失败响应不会污染缓存；
- 台词候选随机抽取并记忆最近 4 句，任务调度记忆最近 3 项；稍后提醒会在到期后优先恢复，只有用户明确选择后才消费，重启服务后仍保留状态；任务冷却、提醒与防重复历史按资源包隔离；
- 内置 15 类任务，包含晨间计划、午饭、晚间回顾、雨雪冷热提醒、专注与伸展，以及玩法邀请；
- 任务可声明时段、天气和 `playMode`，关闭“随机邀请玩法”后不会回退误选游戏任务；
- 重力模式：读取重力/加速度传感器，以 Android 全屏坐标和当前屏幕旋转计算真实下落方向，支持拖起、下落、弹性碰撞与四边停靠；
- 边框散步/跑酷：系统栏、手势区和异形屏挖孔统一纳入安全区；脚点精确贴边，身体始终朝屏内，转角后用镜像表达切线运动方向；
- 主页捉迷藏、炸弹人和贪吃蛇：使用带 Dock 保留区的安全拟态游戏场、障碍、寻路、计分、连击、轨迹、粒子、音效、震动与复原动画；贪吃蛇支持滑动转向，炸弹人支持点选目标/放置炸弹；
- `io.sweetpet.game-kit/1`：资源包声明头像裁切、支持玩法和主题色；
- 动作 `motion` 元数据：朝向、镜像能力、旋转策略、落脚锚点和场景标签；落脚锚点已参与碰撞、贴边、旋转及动作切换定位；
- `behavior` 入口可为日常、甜蜜、安静三种交互风格声明动作权重、兜底动作与用户拖放后的原地休息时长；
- 动态玩法设置采用独立折叠分组，可分别关闭天气联网、高级玩法和随机玩法邀请。

## 玩法安全边界

Android 在不使用无障碍、屏幕捕获、使用情况访问或启动器私有接口时，普通应用不能可靠读取和移动真实桌面图标，也不能持续可靠判断任意启动器是否仍位于前台。因此三个主页玩法启动时会主动回到系统主页，只操作本应用绘制的非触摸拟态图标；返回本应用、停止、超时或抓住头像后会完整复原拟态层，真实图标始终不变。若用户直接从主页进入其他应用，玩法仍可能保留到被抓住或自动超时，这是本版主动不申请敏感权限后的边界。

## 权限

- `INTERNET`：用户开启局域网上传时提供网页上传，并在开启动态天气后访问天气服务；
- `ACCESS_NETWORK_STATE`：只用于优先显示电脑能够访问的 Wi-Fi/以太网地址，避免误选移动数据或 VPN 地址；
- `FOREGROUND_SERVICE_DATA_SYNC`：仅在用户手动开启局域网上传后的 15 分钟短时会话中维持监听，并提供通知关闭入口；
- `SYSTEM_ALERT_WINDOW`：悬浮桌宠和安全拟态玩法层；
- `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_SPECIAL_USE`：带常驻停止入口的悬浮服务；
- `POST_NOTIFICATIONS`：Android 13+ 前台服务通知；
- `SET_WALLPAPER`：切换显示模式时恢复系统背景；
- `VIBRATE`：任务选项和显式游戏反馈，可在设置中单独关闭游戏震动。

应用不申请位置、相册、广泛文件读取/管理、麦克风、通讯录、无障碍或屏幕捕获权限。本地导入只读取用户通过 Android 系统文件选择器明确选中的文件/目录，或由文件管理器以一次性 `content://` 授权主动分享给应用的文件；候选快照位于应用私有缓存，确认安装后才写入应用私有 `files/content-packs`。

## 手机本地资源包

“选择文件（推荐）”支持一次选择多个 `.petpack`，不需要目录授权；若 vivo 系统文档选择器兼容性不佳，可使用“vivo / 文件管理器兼容选择”，也可在文件管理器中用“打开方式/分享”发送到本应用。“扫描目录（可选）”会记住一个只读目录，并可在返回设置页时自动检查。Android 11 及以上不能通过系统目录选择器授权整个内部存储或 Download 根目录，建议先创建 `Download/PetPacks` 子目录后只授权 PetPacks。扫描有单包 96 MB、目录深度、条目数、候选数和累计读取量限制；相同 SHA-256、已安装相同内容以及用户明确忽略的内容不会重复提示。目录授权可随时在应用内撤销，去重/忽略记录也可单独清除。

天气查询只向当前数据源发送用户手动填写的城市名以及正常网络请求所包含的 IP 地址，不发送设备定位、桌宠对话、资源包内容或设备标识。国内免密接口不可用时才回退到 Open-Meteo；Open-Meteo 免费开放接口限非商业用途并要求 CC BY 4.0 署名，商业发布前应复核数据源条款或配置自有合规服务。

## 局域网上传排查

手机与电脑需连接同一个普通 Wi-Fi（访客网络/AP 隔离通常禁止设备互访）。电脑先打开应用显示的简短 `http://IP:端口/` 地址，再输入手机上的 6 位配对码；也可复制“完整链接”作为兼容方式。应用会优先显示当前 Wi-Fi/以太网地址并排除移动数据、VPN 接口；若有多个可用地址会全部列出。上传由带通知关闭入口的 15 分钟 `dataSync` 前台服务持有，切换应用或息屏不会因 Activity 停止而立即断开；若用户强行停止应用、厂商系统终止整个进程或设备重启，会话仍会安全结束。更换网络后地址会自动刷新。仍无法访问时，可暂时关闭两端 VPN/代理及浏览器“始终使用 HTTPS”，并依次尝试应用列出的其他地址。Android 模拟器需要先通过 `adb forward` 转发端口，不能直接使用模拟器内部的 `10.0.2.x` 地址；当前上传页需要 IPv4 局域网。
